# Инструкция по работе с проектом

Это проект Google Apps Script. Файлы `.js` и `appsscript.json` находятся в `scripts/` и связаны с удалённым проектом через `clasp` (настройка `rootDir` в `.clasp.json`).

- Изменяйте код локально и применяйте изменения к Google Apps Script через `clasp push`.
- Если код меняли в веб-редакторе Apps Script, перед локальной работой синхронизируйте файлы командой `clasp pull`, чтобы не перезаписать удалённые правки.
- Для публикации новой версии веб-приложения используйте команды `clasp` отдельно: `clasp push` обновляет код проекта, но сам по себе не обновляет существующее развёртывание.

## Документация

- Описание структуры проекта находится в файлах `docs/*.md`. При любом изменении проекта обновляйте соответствующие файлы в `docs/`, чтобы документация отражала его актуальное состояние.
- `README.md` предназначен только для краткого описания проекта и инструкции по установке. Подробное описание структуры и изменений размещайте в `docs/*.md`.
- Перед чтением документации целиком найдите нужную тему командой `rg -n 'ключевое слово' docs/` и откройте соответствующий файл или раздел. `docs/general.md` служит указателем по тематическим файлам.
