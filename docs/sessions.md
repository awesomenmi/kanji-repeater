# Повторение и сессии

# 4. Правила изменения Score

Обработка выполняется в:

```javascript
processSessionResultV21()
```

## 4.1. Score меньше 3

Независимо от ответа:

```javascript
newScore = oldScore + 1;
```

Примеры:

* 1 → 2
* 2 → 3

## 4.2. Score равен 3

| Результат | Новый Score |
| --------- | ----------: |
| ok        |           4 |
| half      |           3 |
| fail      |           3 |

## 4.3. Score больше или равен 4

| Результат | Изменение |
| --------- | --------- |
| ok        | +1        |
| half      | 0         |
| fail      | −1        |

## 4.4. Ограничение

```javascript
newScore = Math.max(
  1,
  Math.min(22, newScore)
);
```

Допустимый диапазон Score: 1–22.

В текущем `processSessionResultV21()` ограничение Score продублировано. Второй вызов избыточен, но не меняет результат.

# 5. Обработка результата повторения

Функция:

```javascript
processSessionResultV21(
  sessionId,
  result,
  eventId
)
```

Выполняет следующие действия:

1. Получает Script Lock.
2. Находит сессию.
3. Проверяет, не завершена ли она.
4. Проверяет Event ID в LOG и индекс карточки; при незавершённой операции берёт сохранённые значения.
5. Находит текущий элемент.
6. Проверяет статус PENDING.
7. Проверяет допустимость результата.
8. Читает актуальные дату и Score из учебного листа.
9. Рассчитывает новый Score.
10. Добавляет в LOG запись `PENDING` с исходными и рассчитанными значениями.
11. Записывает сегодняшнюю дату и новый Score, затем вызывает `SpreadsheetApp.flush()`.
12. Считывает пересчитанный Countdown.
13. Помечает элемент `PROCESSED`.
14. Передвигает Current Index и при необходимости завершает сессию.
15. После записи изменений помечает запись LOG как `OK`.
16. Возвращает результат обработки.

### Дата

Записывается дата текущего дня с обнулённым временем:

```javascript
const today = new Date();

today.setHours(0, 0, 0, 0);

dateCell.setValue(today);

dateCell.setNumberFormat('dd.MM');
```

### Принципиальное ограничение

Скрипт изменяет только дату и Score в учебном листе.

Countdown не изменяется напрямую.

# 6. Основные функции сессий

## `getOrCreateActiveSessionV22(sheetName)`

Ищет активную сессию для указанного листа.

Если сессия существует — возвращает её.

Если нет — вызывает:

```javascript
createReviewSessionV18(sheetName)
```

В обновлённой реализации используется Script Lock при поиске и создании сессии.

Это защищает от одновременного создания нескольких сессий при повторных нажатиях.

## `createReviewSessionV18(sheetName)`

Создаёт сессию и элементы в SESSIONS и SESSION_ITEMS.

В обновлённой реализации получает данные из общей дневной очереди:

```javascript
getDailyReviewQueueV1()
```

После этого выбирает элементы нужного учебного листа.

Если элементов нет, возвращает:

```javascript
{
  sessionId: null,
  status: 'EMPTY',
  itemCount: 0
}
```

Если элементы есть:

* создаёт Session ID;
* записывает сессию;
* создаёт SESSION_ITEMS;
* присваивает последовательные Item Index;
* формирует Event ID.

Важно: функция не должна самостоятельно получать тот же Script Lock, если вызывается внутри заблокированной `getOrCreateActiveSessionV22()`.

## `getCurrentReviewItemV19(sessionId)`

Возвращает текущий PENDING-элемент активной сессии.

Если подходящего элемента нет, возвращает `null`.

В обновлённом варианте дополнительно читает дату последнего повторения из учебного листа.

## `getSessionStatsV23(sessionId)`

Подсчитывает только элементы со статусом PROCESSED.

Возвращает:

```javascript
{
  total,
  ok,
  half,
  fail
}
```

Используется для итогового сообщения Telegram.
