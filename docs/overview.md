# Общее описание и архитектура

# 1. Общее описание

Kanji Reader — система интервального повторения японских иероглифов.

Пользователь хранит кандзи и историю их изучения в Google Sheets, а повторение выполняет через Telegram-бота.

Основной процесс:

1. Google Apps Script проверяет учебные листы.
2. Находит кандзи, срок повторения которых наступил.
3. Формирует очередь с учётом дневного лимита.
4. Сортирует кандзи по текущему Score: от меньшего к большему.
5. Создаёт сессию повторения.
6. Отправляет пользователю карточку в Telegram.
7. Пользователь выбирает результат повторения.
8. Скрипт изменяет Score и дату последнего повторения.
9. Google Sheets самостоятельно пересчитывает Countdown.
10. Результат сохраняется в журнал LOG.
11. После завершения сессии Telegram показывает статистику.

Дополнительно реализуется механизм временного увеличения дневного лимита через Telegram.

# 2. Архитектура

## 2.1. Распределение ответственности

| Компонент          | Ответственность                    |
| ------------------ | ---------------------------------- |
| Google Sheets      | Постоянное хранение данных         |
| Google Apps Script | Бизнес-логика, сессии и интеграции |
| Telegram           | Пользовательский интерфейс         |
| Script Properties  | Конфигурация и временные настройки |

Google Sheets является основным источником данных.

Telegram не хранит состояние повторений. Все значимые изменения фиксируются в таблице.
